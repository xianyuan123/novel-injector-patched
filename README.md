# 小说注入器 · 自用补丁版

这是 `novel-injector` 的**个人修改版安装包**，只加了两处自己能用到的东西，其余代码未动：

| 改动 | 说明 |
| --- | --- |
| 自动推进可单独配接口 | 状态栏设置 → 自动推进 → 判定模型，新增「单独配置一个接口」，可填独立的地址 / Key / 模型名，留空则沿用清洗那套配置 |
| 撤销提示条可关 | 状态栏设置 → 剧情进度显示方式 下面新增「删除时显示撤销条」开关，关掉后删除照常生效、不再弹 30 秒浮条 |

## 安装

下载 `novel-injector-2026-11-05.zip`，在酒馆里：

- 扩展 → 安装扩展 → 从压缩包安装，或
- 解压到 `public/scripts/extensions/third-party/novel-injector/`

装完刷新页面。版本号已改成 `2026.11.05`，方便和原版区分。

## 注意

- 原插件更新覆盖后，这两处补丁会丢失，需要重新打。
- 改动文件都留了备份：`index.js.bak` / `lib/transbook-system.js.bak` / `template.html.bak`（最早的原版），`.bak2` 是加撤销开关之前的版本。
